# MinerU 索引清洗与 RAGAS 重测（2026-10-13）

此页保存2026-10-13冻结语料与评测结果；2026-10-14代码与文档复核见[最新核查](review_20261014.md)。表内107/106/1是当日历史测试记录，不是当前测试数。

固定 20 题中，双方四项完整的 20/20 对上，等权均值由原始 MinerU 的 0.8330 变为清洗后的 0.8653，观察到上升 0.0323。配对 Bootstrap 95% 区间包含零，尚不能确认稳定提升。

本次只修改 med_rag 的 Markdown 索引清洗和 RAG 文档。简历只更新 RAG 项目的文档处理与成果：MinerU 作为实际处理步骤写入，不单列技能、不声称其已带来质量提升；Agent 与其他项目保持原文。

## 实现与保留范围

`src/offline_pipeline/markdown_normalizer.py` 在 `DataCleaner.clean_documents` 的 Markdown 路径调用。原始 MinerU 抽取文件保留于 `data/clean_md_mineru/`，本轮核对副本为 `data/clean_md_mineru_index/`；归一化后的正文才送入现有父子分块和 BGE-M3。

- 去除 Markdown 链接目标、引用式链接定义、空 HTML 锚点和属性，保留链接标签与图片替代文字；嵌套括号使用 Markdown 解析器处理。
- 保留正文、标题层级与列表；HTML 表格转为 Markdown 表格，保留表题、单元格和跨行/跨列关联，跨跨度单元格按列展开。
- 上标/下标转为 `^`/`_`，例如 `10<sup>9</sup>` → `10^9`；保留医疗比较符号、数值、单位及代码原文。
- Markdown 保留段落边界、表格分隔行与列表缩进，不套用原 PDF 的重复行和纯符号行清理。失败抛错，中止入库。
- PDF、DOCX、PPTX、TXT 的加载和清洗规则继续沿用原实现；现有字符分块仍可能切断大表格。

## 语料与工程验证

| 项目 | 原始 MinerU 索引文本 | 归一化后 |
|---|---:|---:|
| 文档 | 2,572 | 2,572 |
| 父块 | 5,982 | 4,064 |
| 子块 | 29,181 | 17,629 |
| 可识别完整链接目标/HTML 标记占子块字符 | 37.68% | 0.0010%（56/5,445,962字符） |

子块减少 39.59%。标记比例只统计完整标记；截断标记可能未计入，因此它不是所有非正文字符的精确比例。表格分隔符属于保留结构，不算 HTML 噪声。

2,572 篇逐篇归一化幂等、可见数值保留与标题文字核对通过，原文与归一化后都能解析出 1,628 张表格。表格单元格文字核对未发现丢失；五个复合单元格因新增列表编号和嵌套表格列名而无法连续匹配，进一步字符序列对照未发现源文字删改。数值核对从可见文本计数并排除 URL 编码数字，标题核对忽略显示空白；这些检查不能替代医学语义和表格关联人工审阅。全部新分块 ID 唯一、子块长度不超过 400、父引用与冗余正文一致。

完整工程回归 107 项：106 项通过，1 项因主 RAG 环境未安装隔离 SDK 跳过；独立 MinerU 环境 11 项专项测试全部通过，含真实 SDK 解析。新清洗 10 项测试覆盖链接、引用、HTML 结构、表格跨度、科学计数、代码与失败传播。

旧 `data/clean_md/` 和 `data/split_docs/docs.json` 保留；历史文件的 2,570 篇、3,936 父块、16,880 子块属于旧索引。本轮新方案为 2,572 篇、4,064 父块、17,629 子块，共 21,693 块，**不是当前线上 Milvus 集合计数**。

## 配对实测

| 指标 | 原始 MinerU | 清洗后 | 配对差值 | 差值 Bootstrap 95% 区间 | 有效配对 |
|---|---:|---:|---:|---|---:|
| 忠实度 F | 0.8939 | 0.8735 | -0.0204 | [-0.0966, +0.0526] | 20/20 |
| 答案相关性 AR | 0.6297 | 0.6875 | +0.0578 | [-0.0279, +0.1694] | 20/20 |
| 上下文精确度 CP | 0.9000 | 0.9500 | +0.0500 | [+0.0000, +0.1500] | 20/20 |
| 上下文召回率 CR | 0.9083 | 0.9500 | +0.0417 | [-0.0500, +0.1667] | 20/20 |
| 四项等权均值 | 0.8330 | 0.8653 | +0.0323 | [-0.0312, +0.1272] | 20/20 |

四项等权均值是本地汇总，非 RAGAS 官方总分；缺项保留为空，各指标仅比较双方有有效值的同题集合。Bootstrap 使用 5,000 次配对重采样、种子 42，只描述这组开发题，不覆盖供应商或模型随机性。

同题、同配置的上一轮旧 BS4 冻结对照均值为 0.8647；本轮清洗方案为 0.8653，与旧方案配对差值 +0.0005，95% 区间 [-0.0629, +0.0552]。该补充比较复用旧方案冻结答案与分数，衡量抽取迁移加索引清洗的总体变化，不单独归因于 MinerU。

12/20 题的来源组合改变。清理标记不仅减少字符，还改变切分边界、向量和实际上下文，故新方案重新检索、生成和评分。

## 评测条件与边界

- 固定题号：`[4, 14, 27, 33, 43, 52, 62, 68, 99, 104, 123, 151, 157, 164, 166, 169, 175, 180, 185, 201]`，沿用既有开发样本，未按本轮分数选题。
- 原始 MinerU 对照复用上一轮冻结的 20 个检索结果、答案和有效分数，逐项核对 question、answer、contexts、ground_truth 完全一致，并记录原文件 SHA256；清洗后 20 个答案及其四项分数重新生成和评分。旧 BS4 冻结结果另作总体变化补充对照，不混入原始 MinerU 与清洗后的主配对统计。
- 生成：`deepseek-ai/DeepSeek-V4-Flash`，temperature=0.2、max_tokens=1024；同一 grounding 提示词，标题补召回和生成后复核关闭。参考答案只给裁判。
- 裁判：`Qwen/Qwen3-30B-A3B-Instruct-2507`，RAGAS 0.2.6、temperature=0、JSON mode=false、中文 AR、strictness=3。记录的生成/裁判模型名不同，供应商别名独立性未另行核实；无备用评分引擎。
- BGE-M3 与 BGE-reranker-large 使用本地 CUDA/fp16；父/子 2,000/400、重叠 60；每路召回 16，dense/sparse 权重 1.0/0.7，融合前按 `0.5 + atan(IP)/π` 映射，前 5 个子块回溯父块，重排后最多 2 条上下文。
- 本机 Milvus/Docker 未启动，双方用全库内存精确 IP 检索；它替代线上 IVF_FLAT/nprobe=16，稀疏检索保留全部查询词，与线上 drop_ratio_search=0.2 有差异。现有 Milvus 集合尚未重建验收。
- 这是全语料范围的 20 题开发试验，**不代表 210 题全量评测、线上质量或临床准确率**。历史 0.7298 对应不同冻结输入与混合裁判，不与本轮直接相减。
- 外部 API 只接收公开 MSD 摘录和项目模拟题/参考答案；43 个实际来源核对到公开 canonical URL。简历与联系人内容留在本地。
