# 医疗 RAG 项目汇报素材

> 2026-10-08 核对代码、本地数据与历史报告。实现细节见 [架构说明](../architecture.md)。

## 项目介绍

项目提供离线建库、在线问答和 Ragas 评测。FastAPI、Streamlit 与 CLI 共用核心编排；Vite 前端用于17页项目汇报。离线用2000/400字符父子分块、BGE-M3双表示与Milvus；在线通过缓存和FAQ快通道复用高频答案，医疗深通道使用四种策略、混合检索和BGE重排，返回答案与来源。

## 工程成果

- 本地2570篇、20816块，父子引用与冗余正文一致；3936条旧父类型已备份修正。
- 缓存保留数值标点，并按来源、策略和历史隔离结果；命中缓存仍保存会话。
- FAQ 零匹配回退RAG；带历史、来源或显式策略的请求进入深通道。
- 意图、检索和重排故障显式L2；分块与向量化失败终止，避免静默部分成功。
- 评测保留缺项和真实零分，统一引擎与统计分母，综合分从原始评分一次舍入。
- 历史210题四项均值0.8163/0.5007/0.8405/0.7619，综合0.7298；GLM主裁判与DeepSeek补评来源留档。
- 独立启动、HTTP请求、真实DOCX和Streamlit交互有回归；演示页验证翻页和桌面/手机缩放。

## 演示与计划

会话ID用于记录，客户端读取最近5轮再提交messages；生成使用最近3条历史消息。追问写明讨论对象。后续重点为真实问题集、FAQ标定、多轮检索改写、缓存版本、内联证据和并发调度。

2026-10-08 连接检查时，Milvus、Redis、MySQL和问答API端口未监听；启动后的实际模型与中间件联调单独记录。来源授权以数据提供方材料确认。
