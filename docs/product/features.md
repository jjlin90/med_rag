# 项目汇报事实清单

> 2026-10-08 统一到当前代码与本轮本地核算，详细说明见 [架构文档](../architecture.md)。

1. 2570 个清洗 Markdown、20816 条分块，16880 子块与 3936 父块；类型标签已修正。
2. 父/子上限 2000/400 字符，重叠 60。
3. BGE-M3 输出 dense1024 + sparse，关闭 ColBERT。
4. Milvus IVF_FLAT/IP + 稀疏倒排/IP，dense1.0、sparse0.7。
5. L0：每路融合 Top-16 子块 → 前5回溯去重 → 代表子块精排 → 最多2条父上下文。
6. API：query缓存 → FAQ缓存/MySQL/BM25 → RAG；FAQ 原始分大于0且 softmax 达到0.85。
7. 四策略：direct、HyDE、subquery、backtracking。
8. L1 产出子片段；L2 附故障原因并跳过缓存；有依据但生成失败返回原文摘录。
9. 会话保存最近5轮；客户端提交历史，生成使用最近3条历史消息。
10. 历史210题 F/AR/CP/CR 为0.8163/0.5007/0.8405/0.7619，逐条等权综合0.7298。

汇报页按“已实现行为、实际验收、后续计划”组织内容。生产性能、数据分发授权和模型临床效果采用各自独立证据；FAQ 0.85 描述相对排序阈值。
