# PPT 页面事实清单（代码核验版）

制作 PPT 时只使用下列仓库可核验信息：

1. 2570 个清洗 Markdown；20,816 条分块记录。
2. 逻辑子块 16,880、父块 3,936；400/2000 字符，重叠 60。
3. BGE-M3 输出 dense+sparse，ColBERT 关闭。
4. Milvus 代码配置 sparse 0.7、dense 1.0。
5. 正常 L0：Top-16 子块 → 截 Top-5 → 父块回溯 → 最佳子块证据重排 → Top-2 父块。
6. query cache → FAQ/BM25 → RAG；FAQ 阈值 0.85。
7. 四策略：direct、HyDE、subquery、backtracking。
8. L1 返回子块；L2 无证据拒答。
9. 最新评测 F/AR/CP/CR=0.8163/0.5007/0.8405/0.7619，四项等权平均 0.7299。

不得把下列内容画成已实现：OCR、答案内联引用、流式 API、服务端自动加载历史、RBAC、多租户、影子集合、灰度发布、审计、生产部署或固定延迟/QPS。数据权威性、授权、隐私和合规需要外部材料，不能由代码背书。
