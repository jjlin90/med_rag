本次用户授权清除 GitHub 个人信息。清理范围包含历史中的 `artifacts/`（个人资料、简历、浏览器状态、审查临时文件）、私人资料脚本、`.mimosa/`、前端安装依赖与 PPT 工具元数据。原始镜像只保存在本地已忽略的 `artifacts/security_20260930/`，不得重新推送该备份。

历史重写会改变提交 ID，旧克隆应重新克隆或在保留本地工作后同步新的历史，不要合并或推送旧历史。GitHub 分支和标签的可达历史清理与第三方克隆、fork、平台缓存是不同范围；后者不能通过一次 Git 推送保证删除。
