# 医疗知识库 — 数据来源与合规说明

## 一、数据源基本信息

本项目检索知识库来源于**《默沙东诊疗手册（大众版）》**公开免费的医学科普资源。

默沙东手册是全球权威、公开、公益性的医学科普平台，面向普通大众提供标准化、通俗易懂的常见疾病健康知识，内容严谨、无商业诊疗导向，适合用于 AI 科普问答场景。

## 二、数据规模与覆盖范围

本次使用**中文大众版**数据集，经清洗后形成的知识库规模如下：

| 阶段 | 位置 | 规模 |
|------|------|------|
| 清洗后文档 | `data/clean_md/` | 约 **2570 篇** Markdown |
| 分块数据集 | `data/split_docs/docs.json` | 约 **20816 个**文本块 |
| 向量库 | Milvus 集合 `med_msd_consumer_chunk` | 与分块一一对应 |

分块构成（父子分层分块）：**16880 个子块**（400 字符，参与检索）+ **3936 个父块**（2000 字符，提供生成上下文，占 18.9%）。
检索时通过 `chunk_type` 字段过滤下推，父块不占用召回名额。

内容主要类目：

- 内分泌疾病：1 型/2 型糖尿病、甲亢、痛风、高血脂等。
- 心脑血管：高血压、冠心病、动脉硬化、脑卒中相关科普。
- 呼吸系统：哮喘、支气管炎、肺炎等常见慢病。
- 消化、骨科、皮肤、儿科、妇科、全科日常健康知识。
- 常规治疗、康复护理、饮食、运动、并发症预防等科普内容。

## 三、数据处理合规性说明

1. **使用场景合规**：仅用于**人工智能技术学习、学术研究、开源演示**，非商业用途、非临床诊疗用途。
2. **数据来源合规**：依托公开可访问的公益性科普资源，无侵权爬取付费、私有、涉密医疗数据。
3. **二次处理合规**：仅对公开 HTML 页面做清洗、结构化转换，去除广告、版权、冗余信息，保留科普内容，无篡改、伪造医疗信息。
4. **无患者隐私数据**：知识库**不包含任何个人病历、患者隐私、就诊记录、涉密医疗数据**，无隐私泄露风险。

## 四、内容使用限制与免责规范

- 知识库内容仅作**健康科普参考**，不构成执业医师的诊断、治疗、用药建议。
- 禁止将本项目模型与知识库用于商业诊疗、线上问诊、临床辅助诊断等医疗服务场景。
- 所有 AI 生成回答存在概率性误差，身体不适必须前往正规医疗机构就诊。

## 五、数据处理规范

为保证知识库质量，项目对原始数据执行标准化处理：

- 彻底清除页面冗余组件：导航、侧边栏、页脚、版权、作者、修订记录、自测题、外链资源。
- 统一文档结构：标准化标题层级、规整段落格式、清理无效空行与乱码。
- 过滤低质量、无效、过短文本，保证内容有效、严谨、干净。
- 结构化分层存储，区分**原始数据（`data/raw/`）→ 清洗数据（`data/clean_md/`）→ 分块数据（`data/split_docs/`）**，流程可追溯、可复现。

## 六、总结

本项目数据源**权威、公开、合规、无隐私风险**，处理流程标准化，使用场景仅限技术学习与学术演示，符合开源项目合规要求，无版权、隐私、医疗合规风险。
